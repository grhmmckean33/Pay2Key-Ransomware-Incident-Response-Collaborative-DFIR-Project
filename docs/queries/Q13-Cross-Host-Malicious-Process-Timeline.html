Q13 — Cross-Host Malicious Process Timeline

Correlated malicious process execution across affected hosts to support the wider investigation timeline.

Portfolio context: This query is reproduced from the investigation query set used in the collaborative Pay2Key case. It is presented here to demonstrate the analytical method supporting my scope-assessment workstream.
// Q13 - Cross-Host Malicious Process Timeline
// Purpose: correlate malicious execution across the two confirmed compromised hosts.
DeviceProcessEvents
| where FileName in~ ("mimikatz.exe","pscan241.exe","3.exe",
  "procdump.exe","netscan.exe","masscan.exe","sfx-i386-amd64.exe",
  "browser.exe","shellcode.exe")
| project Timestamp, DeviceName, FileName, InitiatingProcessFileName, AccountName
| sort by Timestamp asc
