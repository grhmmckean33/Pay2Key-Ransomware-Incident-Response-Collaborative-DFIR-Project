Q15 — DarkKomet C2 (Actor 3)

Follow-on validation of the separate DarkKomet callback used to support attribution separation.

Portfolio context: This query is reproduced from the investigation query set used in the collaborative Pay2Key case. It is presented here to demonstrate the analytical method supporting my scope-assessment workstream.
// Q15 - DarkKomet C2 Connection (Actor 3)
// Purpose: validate the separate DarkKomet callback identified during scope review.
DeviceNetworkEvents
| where RemoteIP == "69.42.215.252"
| project Timestamp, DeviceName, RemotePort, InitiatingProcessFileName, ActionType
| sort by Timestamp asc
